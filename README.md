# игра "угадай число"
простая консольная игра на python. компьютер загадывает число в заданном пользователем диапазоне, а игроку необходимо его угадать. 
поддерживаются команды для просмотра истории угаданных чисел и смены диапазона в процессе игры.

## функционал
- выбор диапазона чисел.
- подсказки от компьютера: число больше/меньше.
- история угаданных чисел.
- смена диапазона угадываемых чисел в процессе игры (от 1 до ограничений системы).
- подсчёт попыток и их среднее количество.
- обработка ошибок ввода и прерывания игры (ctrl + c).

## установка
1. скачайте репозиторий или скопируйте файл `game.py`.
2. убедитесь, что установлена версия python 3.x.

## использование
1. в командной строке перейдите к расположению файла.
2. введите в консоль python game.py.

## технологии
- python 3.11
- модули random, time
